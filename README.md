This project is a required coursework for the Introduction to Data Science course at the University of Lethbridge

The project consists of three phases:

Phase 1 (100/100 for 5% weight):
This stage is about the descriptive analysis of a dataset by giving a report about the information we can gather
based on the dataset that we see. I worked on a dataset that regards farmers and their risk management, providing an informative
report regarding the data collection process, variables, limitation evaluation, summary, and providing potential research
qusestions. This is to help other students who will work on this dataset to have background context for further analysis.

Phase 2 (100/100 for 10% weight): 
During this stage, we were given a random dataset and a report that was created by another student from Phase 1. The goal
is to clean and prepare the data to answer a chosen research question from the given options. I applied data cleaning techniques such
as NA data handling, variable retention and deletion, variable renaming, outlier detection, and invalid data handling. Additionally,
I created a report where I outlined the overview of the dataset and the techniques I used to clean the data. Moreover, I used the 
report to justify my decision, ensuring that the professor understands my thinking process and assess my decisions regarding the techniqes
I used.
